Interface layout
Sidebar: the app title and tagline, the five-item navigation menu, and a short footer.
Home: a hero banner, a row of metric cards, and “Featured” and “Quick Start” card rows.
Search Resources: a keyword box with filters for medium and course level, followed by a card grid of the matching results.
Browse Exemplars: a filter bar, then a grid of exemplar cards with a modality tag, course, and an expandable instructor commentary.
Lesson Plans: expandable containers with objectives, a timeline, and materials for each plan.
Rubrics: a selector and a criteria-by-performance-level table in a card container.
